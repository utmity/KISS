# ウィジェット自由配置 + スワイプ統合版

PR #2の４列グリッド編集・保存とPR #3のウィジェット上のスワイプを統合したDebug版です。

- 長押し → 編集開始、ドラッグ・右下リサイズ、右上メニュー。編集中はウィジェットスワイプを起動しません。
- 非編集中のウィジェット端24dp（初期設定）からのスワイプは既存KISSのジェスチャー設定を実行します。
- スワイプ認識時は子ViewへCANCELを送信します。2本指スクロール、通常タップを維持する設計です。
- 設定→ジェスチャー→ウィジェット上のスワイプで無効／端から／スクロール領域以外の全体、認識距離48／72／96dp。
- ウィジェット編集時は長押しを優先し、編集操作はWidgetGridへ渡します。
- DebugアプリIDは `fr.neamar.kiss.widgets.debug`。通常版KISS、Ctrl版、入力計測版と共存します。
- PR #1、#2、#3はそのまま保持し、独立統合ブランチで作成します。

## 検証すること
CIではGradleによるビルド、lint、JVMテストを確認してください。既存のWidgetGridTest、RealWidgetTest、WidgetSwipeTestはAndroidの実機/エミュレーター向けであり、通常のCIでは実行されません。端末では①時計と天気の横並び、②長押しから移動・リサイズ、③編集開始後のスワイプ誤起動なし、④編集終了後の端スワイプ、⑤内部ボタン・スクロール、⑥2本指スクロール、⑦再起動後の配置復元を確認してください。

既存PR単独のテスト結果は統合版の実機保証ではありません。詳細は `docs/widget-layout-ja.md` と `docs/widget-swipes-ja.md` を参照。
